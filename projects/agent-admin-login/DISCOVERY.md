# DISCOVERY.md — agent-admin-login

> 本文档信息来自本轮（SO-003）针对该项目的需求收集，未沿用其它项目设定。

## 1. 项目目标
- 为「Agent 后管系统」提供一个**登录页面**（单页面）。
- 后台管理系统（admin dashboard）登录入口，专业、克制、现代。
- 前端演示态：不接真实后端，登录交互做空值/格式校验 + 提交 loading + 模拟反馈。

## 2. 目标用户
- 技术 / 运维 / 平台管理者（B2B 内部系统使用者）。
- 期望：快速、专业、低干扰，输入即用，错误提示清晰。

## 3. 页面结构（单页）
- 左侧（PC）：品牌区 / 产品叙事（Agent 后管系统标识 + 一句价值描述 + 状态/能力点缀）。
- 右侧（PC）：登录卡片
  - 账号输入（用户名/邮箱）
  - 密码输入（含显示/隐藏切换）
  - 记住我（checkbox）+ 忘记密码（链接）
  - 主登录按钮（账号密码，演示态 loading + 反馈）
  - 分隔线 + 低调「企业 SSO 登录」占位按钮（不接真实后端）
- 底部：版权 / 备案占位 / 版本号。
- Pad/H5：左右分屏收敛为单列，品牌区压缩为顶部精简标识，登录卡为主视觉。

## 4. 设计方向（Design Read + 三档位）
- **Design Read**：后台管理系统登录页 for 技术/运维管理者，Linear-clean 克制语言，倾向 Tailwind utilities + 中性深色基底 + 单一高对比强调色 + 极克制动效。
- **三档位**：
  - `DESIGN_VARIANCE: 4`（克制、偏对称，但用左右分屏避免居中套路）
  - `MOTION_INTENSITY: 3`（仅入场淡入/位移 + 交互态反馈，尊重 reduced-motion）
  - `VISUAL_DENSITY: 4`（标准应用密度，表单呼吸感足够）
- **配色**：中性基底 zinc/slate 深色；强调色 Electric Blue（`#3b82f6` 系），**禁用 AI 紫渐变**；单一强调色全页锁定。
- **字体**：系统/中性 sans（Inter 系可接受——属克制后台场景的 override 条件）。
- **圆角锁**：统一 12px 卡片 / 10px 输入 / 10px 按钮（同一尺度）。
- **anti-slop 纪律**：无霓虹外发光、无纯黑、无三等宽卡片套路、表单 label 在输入框上方、按钮/输入/占位符均过 WCAG AA 对比、CTA 单行不换行。

## 5. 适配目标
- PC 为主（≥1024：左右分屏）。
- Pad（768–1023）：单列居中，卡片为主，品牌区精简为顶部。
- H5（≤767）：单列全宽，触控热区 ≥44px，首屏直达登录表单。
- 断点：h5Max 767 / padMin 768 / pcMin 1024。
- 触控：输入与按钮高度 ≥44px；hover 效果均有非 hover 降级。

## 6. 交互/状态（演示态）
- 空值校验：账号、密码必填，失焦/提交时校验。
- 格式校验：账号最小长度；密码最小长度。
- 提交：按钮进入 loading（禁用 + spinner），约 1.2s 后模拟结果。
- 模拟反馈：演示账号 `admin / admin123` 成功（顶部成功提示），其它组合返回「账号或密码错误」内联错误。
- 错误态：内联在输入下方 + 整体错误条；密码可见切换。
- SSO 按钮：点击给出「企业 SSO 暂未接入（演示）」的轻提示，不跳转。

## 7. 假设（待确认，本轮授权基于合理假设先做一版）
- 品牌名暂用「Agent 后管系统 / Agent Admin」，logo 用内联字母标记占位。
- 演示账号 admin/admin123 仅用于演示成功路径。
- 无真实接口，全部前端模拟。
