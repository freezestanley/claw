# DISCOVERY — user-list-table

> 用户已授权按默认假设直接开工，以下假设均标注「待确认」，交付时列出。

## 目标
通用用户列表页 demo：展示用户表格，支持搜索/筛选/分页/列排序/行详情查看（只读，无写操作）。

## 受众
后台管理使用者 / demo 演示场景。

## 页面结构
- 顶部标题栏 + Base URL 可配置入口
- 搜索筛选栏：q 关键字 / role 下拉(admin/user/editor) / department 输入；多条件 AND
- 用户表格：ID / 姓名 / 邮箱 / 角色 / 部门；列头点击排序（前端）
- 分页栏：上一页/下一页/页码数字，pageSize(10/20/50)，显示总条数
- 行「查看」按钮 → 轻量弹层展示详情
- 空态 / 加载态 / 错误态兜底

## 风格（Design Read）
- 页面类型：管理后台列表页（功能型，非营销）
- 受众：内部操作者
- 风格语言：清新简约管理后台风，浅色、克制、信息密度适中
- 设计体系：DESIGN_VARIANCE=low / MOTION_INTENSITY=subtle / VISUAL_DENSITY=medium
- 功能型后台页不套营销 hero 模板，重在清晰可用

## 数据源 / API
见 API.md。真实接口 `GET /users/search`；不可用时 mock 降级。

## 适配
PC（≥1024）/ Pad（768–1023）/ H5（<768，表格转卡片或横向滚动）。
