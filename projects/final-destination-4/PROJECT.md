# PROJECT.md — 死神来了4 宣传官网

- **slug**: `final-destination-4`
- **类型**: 恐怖电影宣传官网（中文单页 / 虚构作品，非真实版权素材）
- **stack**: Vite + 原生 JS + Tailwind CDN，自包含单页面
- **状态**: 开发中

## 目标
为虚构恐怖片《死神来了4》做一个暗黑压抑、有宿命感的中文单页宣传站，PC/Pad/H5 自适应。

## 模块顺序
1. Hero（片名 + slogan「死亡早已为你排好顺序」+ 上映日期 + 宿命倒计时）
2. 剧情简介
3. 主演 / 角色卡
4. 预告片占位（播放按钮）
5. 剧照画廊占位
6. 上映信息 + 购票/预约 CTA
7. 页脚（分级提示 R级 / 16+）

## 关键约束
- 不引用任何受版权保护的真实电影素材，全部用暗黑风 SVG/CSS 占位。
- 上映日期占位：「2026 万圣节档 · 10/31」，前端倒计时。
- 尊重 `prefers-reduced-motion`。
