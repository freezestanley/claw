# DISCOVERY.md — H5 贪吃蛇

## 目标
生成一个可直接游玩的 H5 贪吃蛇游戏界面。

## 用户与场景
- 主要场景：手机浏览器（H5），同时兼容 Pad 与 PC。
- 单人休闲小游戏，无登录、无后端。

## 结构
- HUD：当前分 + 最高分
- 棋盘：20×20 Canvas 网格
- 控制区：屏幕 D-pad + 暂停/重开 + 提示
- Overlay：开始 / 暂停 / 结束三态

## 风格
- 深色科技风（slate 深蓝底 + 青绿渐变蛇身 + 金色食物）
- 圆角卡片、发光阴影

## 适配
- H5（≤767）：竖屏为主，棋盘占满宽度，大号触控按钮（≥44px）
- 横屏（矮屏）：棋盘与控制区左右布局
- Pad / PC：键盘为主操控，D-pad 保留

## 假设（无需进一步澄清即可实现）
- 经典规则：撞墙/咬到自己即结束
- 食物随机刷新，吃到 +1 分
- 最高分本地持久化
- 无品牌素材需求 → 纯 CSS/Canvas 绘制
- 无 API 需求

## 状态
Readiness Gate：素材、API、预览方式均无 blocker → 已进入实现。
