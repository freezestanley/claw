# HANDOFF.md — H5 贪吃蛇

## 当前状态
首版界面与玩法已实现，本地 Vite 预览验证中。

## 已完成
- 完整贪吃蛇引擎（移动/吃食/加速/碰撞/计分/最高分持久化）
- 三套操控：键盘(方向键/WASD/空格) + 屏幕 D-pad + 棋盘滑动
- 响应式：H5 竖屏 / 横屏分栏 / Pad / PC
- 开始/暂停/结束 overlay 状态机
- 高 DPI Canvas 自适应

## 如何预览
```bash
cd projects/h5-snake-game
pnpm install && pnpm dev   # http://127.0.0.1:4321
```

## v0.2 新增
- 🔊 音效：Web Audio 合成（开始/吃食/结束），无音频文件依赖，移动端首次手势自动解锁
- 📳 震动：吃食 / 结束触发 navigator.vibrate（仅支持设备生效）
- 🔁 穿墙模式：开关开启后撞墙从对侧穿出
- 控制区新增三个可切换开关（音效 / 震动 / 穿墙），新增 src/audio.js
