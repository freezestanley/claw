# DISCOVERY.md — 女装网店首页

## 来源
经 main 转达的用户需求：生成一个女装网店页面。用户未给更多细节 → 按合理默认假设直接出页面。

## 目标
单页女装电商首页，具备商品展示、分类、购物体验感。

## 默认假设（用户未指定，先行实现，待确认）
- 页面类型：单页首页（非完整电商系统）
- 品牌名：MAISON LÉA 蕾雅（占位）
- 风格：现代简约时尚，奶油白 + 大地陶土色（女装通用耐看基调）
- 品类：连衣裙 / 外套 / 针织 / 配饰
- 商品图：内联 SVG 时装插画占位（图像工具不可用，无真实图）
- 购物：前端购物袋演示，无真实结算后端

## 需用户拍板的关键项（已转交 main 提问）
1. 品牌名与定位（少女/轻熟/高奢？）
2. 风格色调是否就用大地色系，还是要更甜/更冷/更艳
3. 页面范围：只首页，还是要商品详情页 / 购物车结算 / 会员中心
4. 是否有真实商品图与文案

## 适配
H5 单列、PC 多列网格、触控热区 ≥44px、不依赖 hover（quick-add 在触屏常显）

## 状态
无 blocker（占位策略已批准）→ 已进入实现，等待用户细化后迭代。
