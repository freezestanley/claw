# PROJECT.md — MAISON LÉA 蕾雅 · 女装网店首页

- **slug**：`womens-fashion-store`
- **类型**：单页女装电商首页（H5 优先，PC/Pad 兼容）
- **技术栈**：Vite + 原生 JS + Tailwind(CDN) + Google Fonts
- **风格**：现代简约时尚，奶油白 + 大地陶土色 (cream #f7f3ee / clay #c98a6b / charcoal #2b2825)
- **状态**：active（默认假设版，待用户细化）

## 页面结构
公告滚动条 → 导航(含购物袋) → Hero → 品类入口(4) → 本季新品(8 款, 可加购) → Lookbook 穿搭 → 价值主张 → 会员订阅 → 页脚 → 购物袋抽屉

## 交互
- 加入购物袋 → 右侧抽屉滑出、角标弹跳计数、小计实时累计
- 移动端汉堡菜单、邮箱订阅、滚动入场动画

## 文件
- `index.html` — 入口 + Tailwind 主题 + 字体
- `src/main.js` — 整页内容 + 购物袋/菜单/订阅/动画
- `src/art.js` — 内联 SVG 时装占位插画
- `src/style.css` — 动画、抽屉、按钮、毛玻璃导航

## 预览
```bash
cd projects/womens-fashion-store
pnpm install
pnpm dev   # http://127.0.0.1:4323
```
