# DISCOVERY.md — 篮球鞋网店首页

## 来源
经 main 转达的用户需求：生成一个篮球鞋网店页面。描述较简短 → 按合理默认假设直接出高质量首页。

## 目标
单页篮球鞋电商首页：产品网格、Hero、品牌调性、CTA、购物体验感。

## 默认假设（用户未指定，先行实现，待确认）
- 页面类型：单页落地首页（非完整电商系统）
- 品牌名：APEX KICKS 锋锐（占位）
- 风格：运动潮流暗色高能量，炭黑 + 电光绿 + 烈焰橙
- 受众：篮球爱好者 / 球员，强调性能（缓震/抓地/护踝/轻量）
- 球鞋图：内联 SVG 插画占位（图像工具不可用，无真实图）
- 购物：前端购物袋演示，无真实结算后端

## 需用户拍板的关键项（已转交 main 提问）
1. 品牌定位：自有品牌 vs 多品牌集合店？品牌名是否沿用占位
2. 配色风格：暗色高能量是否合意，还是要更干净/更彩色
3. 页面范围：仅首页，还是要商品详情页 / 购物车结算 / 会员登录
4. 是否有真实球鞋图、型号、参数与价格

## 适配
H5 单列、PC 三列网格、触控热区 ≥44px、quick-add 触屏常显（不依赖 hover）

## 状态
无 blocker（占位策略已批准）→ 已进入实现，等待用户细化后迭代。
