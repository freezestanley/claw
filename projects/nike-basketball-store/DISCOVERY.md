# DISCOVERY — nike basketball store

## 页面目标
做一个以篮球鞋为主的店铺页（演示用），展示多款经典系列球鞋并支持「加入购物袋」的轻量前端购物车交互。非真实电商，纯前端演示。

## 目标用户
篮球鞋爱好者 / 运动潮流人群，浏览球鞋、查看价格、把心仪款式加入购物袋。

## 页面类型
单页面店铺页（Hero + 商品列表 grid + 侧滑购物袋）。

## 页面结构
1. 顶部导航：品牌 wordmark（自绘 swoosh，非真实 Nike 商标）+ 购物袋按钮（含数量角标）。
2. Hero：标语 + CTA，运动风氛围。
3. 商品列表：经典系列各 1–2 款球鞋卡片（SVG 球鞋插画占位），含名称、系列、价格、加购按钮。
4. 侧滑购物袋抽屉：商品行、数量加减、小计、清空 / 结算（演示）。
5. 页脚：免责声明（演示用途、非官方）。

## 风格
Nike 经典黑白红运动风：黑底、白字、红色（#e11d2a 类）作为高亮/CTA。大字号、紧凑字距、运动感排版。

## 商品范围（自选）
- LeBron 系列 ×2
- KD 系列 ×1
- GT Cut 系列 ×1
- Giannis (Freak) 系列 ×1
- Kobe / Mamba 风格经典款 ×1
（均为虚构命名 + SVG 插画，规避商标/产品图版权）

## 适配
PC / Pad / H5 三端。断点 h5≤767 / pad 768–1023 / pc≥1024。触控热区≥44px，不依赖 hover（hover 仅作增强）。购物袋抽屉在 H5 全屏化。

## 交互
- 加入购物袋：数量 +1，角标更新，抽屉小计刷新。
- 抽屉内 +/- 调整数量、移除、清空、结算（演示 alert/toast）。
- 轻量动效用 anime.js（卡片淡入、加购反馈）；尊重 prefers-reduced-motion。

## 状态
Discovery 完成。素材为自绘 SVG，无外部图依赖；无远端 API（纯前端）。Readiness Gate 满足，可进入实现。
