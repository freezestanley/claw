# DISCOVERY — 养老保险落地页

## 页面目标

- 宣传一款**养老保险产品**，引导访问者了解产品价值并产生咨询/留资意向。

## 目标用户

- 中老年人本人及其成年子女（为父母规划养老的群体）。

## 页面结构

1. 顶部导航 + Logo 占位
2. Hero 区：主标题 + 副文案 + CTA + 老人运动主视觉图
3. 产品亮点（3-4 个卖点卡片）
4. 产品介绍文案区（保障内容 / 适用人群 / 领取方式）
5. 老人运动生活方式图文区（晚年活力）
6. 常见问题 / 信任背书
7. 底部 CTA + 页脚（合规免责声明占位）

## 风格

- **暖色调**：米橙、暖黄、暖棕、奶白，传达温暖、安心、活力。
- 圆润、柔和阴影，大字号易读（面向中老年）。

- `Ready`：目标、结构、风格已确认。
