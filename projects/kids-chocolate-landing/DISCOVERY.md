# DISCOVERY.md — 可可熊 CocoBear 儿童巧克力落地页

## 项目目标
单页中文营销落地页，介绍占位儿童巧克力品牌「可可熊 CocoBear」。同时打动两类受众：
- **孩子**：可爱、有趣、想吃、喜欢吉祥物。
- **家长**：安全、放心、营养、信任品牌。

## 受众与语气
- 主受众：3–10 岁孩子的家长（决策者）。
- 次受众：孩子（情感影响者）。
- 语气：温暖、亲切、可信、不浮夸；安全感与可爱感并重。

## Design Read（设计方向）
> Reading this as: **consumer/kids 营销落地页 for 家长（决策者）+ 孩子（情感影响者）**，with a **温暖糖果可爱但克制可信** 的语言，leaning toward **Tailwind 工具类 + 圆润几何 SVG 自绘插画（用户指定）+ 克制的轻量动效**。

### Quiet-constraint 覆盖（来自 taste-skill 0.A）
这是 **kids' products + trust-first 食品** brief，安全感/信任/可访问性 **OVERRIDE** 纯美学冲动：
- 不堆砌花哨炫技；动效服务于愉悦感与引导，可随时降级。
- 家长关心的「营养/安全/原料」模块信息要清晰、可读、对比达标。
- 文案真实、不编造虚假精确数字（无真实数据的数字标注为示意）。

### 三档位（dials）
- `DESIGN_VARIANCE: 6` —— 有活泼错落感，但不做艺术化混乱（孩子/家长都要看得懂）。
- `MOTION_INTENSITY: 5` —— 入场淡入/上浮、吉祥物轻微浮动、滚动揭示；尊重 prefers-reduced-motion。
- `VISUAL_DENSITY: 4` —— 适度留白，糖果世界要透气不拥挤。

### 反默认纪律（anti-slop）
- 不用 AI 紫渐变；主色锁定 **可可棕 + 奶油白**，糖果点缀（橙/红/薄荷）作为唯一一组强调色，全页锁定。
- 不做「居中 hero + 三张等宽卡片」套路：hero 用左文右插画分栏；模块布局家族交替（分栏 / bento / 横向 pill / 手风琴 FAQ）。
- 圆角统一走「全圆润」体系（卡片 ~24px、按钮 pill），符合儿童品牌调性。
- 无 em-dash 作设计装饰。

## 页面结构（默认选 6 个模块）
1. **Hero** —— 品牌主张 + 吉祥物可可熊 SVG + 双 CTA（了解更多 / 哪里购买）。
2. **产品系列** —— 3–4 款占位产品（牛奶可可熊 / 榛子脆脆 / 莓莓夹心 / 薄荷清新），SVG 包装插画。
3. **口味原料卖点** —— 真实可可、无氢化油、低糖配方等卖点（示意文案）。
4. **营养与安全（家长安心）** —— 信任模块：原料溯源、过敏原标注、生产标准（示意）。
5. **品牌故事** —— 可可熊的小故事，建立情感连接。
6. **购买引导 + FAQ** —— 哪里购买（占位渠道）+ 常见问题手风琴。

页脚：占位版权、社媒占位图标、安全声明（非真实结算/非真实品牌）。

## 适配目标（PC / Pad / H5）
- 断点：H5 ≤767，Pad 768–1023，PC ≥1024。
- H5 首屏优先级：吉祥物 + 主张 + 主 CTA；产品系列横向滑动。
- Pad 横竖屏可用；hero 分栏在 Pad 竖屏退化为堆叠。
- 触控热区 ≥44px；不依赖 hover（hover 仅作增强）。
