# DISCOVERY.md — 小满夹物 MANCLIP

## 页面目标
- 类型：**纯品牌展示**单页（非电商，无购物车/结算）。
- 目的：传达甜酷韩系 ins 风发饰品牌形象，吸引学生少女关注/种草。

## 用户
- 学生少女为主，移动端（H5）浏览为主，ins/小红书风格审美。

## 风格
- 甜酷韩系 / ins 风：暖米底 + 焦糖棕 + 亮橘点缀，圆润、柔光、杂志感排版。
- 标题甜美 serif（Fraunces），大图氛围 + 留白。

## 结构（纯展示）
公告条 → 导航 → Hero（品牌主张 + 氛围大图）→ 品牌故事 → 系列/Lookbook 图墙 → 单品精选（图 + 名称 + 一句描述，无价格强调，无加购）→ ins 风格生活方式区 → 关注我们（社媒 + 邮箱订阅占位）→ 页脚。

## 适配
- PC / Pad / H5 三端，H5 优先；最小触控热区 44px；不依赖 hover 作为唯一交互。

## 约束
- 纯前端，无后端/无 API。
- 图片用真实 Unsplash/Pexels 热链（见 ASSETS.md），待人工核对贴题性。
- 动效：轻量入场/视差用 anime.js；尊重 prefers-reduced-motion。
