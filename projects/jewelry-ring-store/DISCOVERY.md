# DISCOVERY.md — 戒指网店首页

## 目标
单页戒指网店首页，传达品牌质感并引导预约/收藏。

## 用户与场景
- 看戒指、了解品牌、留资预约的潜在顾客；H5 优先，兼容 Pad/PC。

## 已确认
- 风格：清新轻奢，米白 + 香槟金
- 品类：戒指

## 默认假设（用户未指定，先行实现，待替换）
- 页面类型：单页首页（非完整电商）
- 品牌名：LUMIÈRE 璐米（占位）
- 商品图：内联 SVG 戒指插画占位（无外部图片依赖）
- 价格 / 门店 / 备案号：占位文案
- 无后端、无 API、无购物车（表单为前端演示）

## 风格细节
- 色：ivory #faf7f2 / cream #f3ece1 / champagne #c8a96a / deep #a8854a / ink #2c2620
- 字体：Cormorant Garamond(展示) + Noto Serif/Sans SC
- 质感：金色渐变文字、细金线分隔、毛玻璃导航、浮动主视觉、滚动入场

## 适配
- H5 单列、PC 多列网格、触控热区 ≥44px、不依赖 hover
