# Discovery

## 页面目标

- 通用「网站运营数据 Dashboard」单页面，集中展示运营核心指标与趋势。

## 目标用户

- 运营 / 增长 / 管理者，需要快速浏览站点关键数据。

## 页面结构

- 顶部栏：标题 + 数据更新时间 + 周期/数据来源标识
- KPI 区：4 个卡片（访问量 PV / 活跃用户 / 转化率 / 营收）
- 图表区一：访问趋势折线（PV + 用户数，近 7 天）+ 渠道占比环形
- 图表区二：地区分布柱状（Top 7 省份）+ 热门页面明细表格

## 风格方向

- 浅色主题，indigo 主色，卡片化布局，圆角 + 轻阴影，干净商务风。

## 适配目标

- PC：≥1024px，四列 KPI + 2/1 分栏图表
- Pad：768–1023px，两列 KPI，图表分栏自适应
- H5：≤767px，单列堆叠，表格横向滚动

## 断点策略

- Tailwind 默认断点：`sm=640` / `lg=1024` / `xl=1280`
- KPI：`grid-cols-1 → sm:2 → xl:4`
- 图表：`lg:col-span-2` 主图 + 单列副图

## 设备使用场景

- PC：办公大屏总览，信息密度高
- Pad：横竖屏均可，触控点击卡片/图例
- H5：移动端速览，首屏优先 KPI，图表与表格下滑查看

## 交互约束

- 不依赖 hover 作为唯一交互（hover 仅作增强，tooltip 触控可点）
- 最小触控热区 ≥ `44px`
- Pad 横屏：支持
- H5 横屏：不强制
