# Discovery

## 页面目标

- 后台管理（admin）单页面：用户列表的数据表格展示 + 分页 + 搜索/筛选/排序。

## 目标用户

- 后台管理员 / 运营，需要浏览与管理系统用户。

## 页面结构

- 左侧边栏（导航：概览/用户管理/订单/统计/设置，PC 常驻，移动端抽屉）
- 顶部栏（标题 + 菜单按钮 + 用户头像）
- 工具条（搜索框 + 状态筛选 + 新增按钮）
- 数据表格（ID / 用户(头像+姓名+邮箱) / 角色 / 状态徽章 / 注册时间 / 操作）
- 分页（页码 + 上/下一页 + 每页条数 10/20/50 + 总数统计）

## 风格方向

- 浅色后台风，indigo 主色，卡片化表格，圆角 + 轻阴影。

## 适配目标

- PC：≥1024px，侧栏常驻
- Pad：768–1023px，侧栏常驻或抽屉，表格自适应
- H5：≤767px，侧栏抽屉（汉堡菜单 + 遮罩），表格横向滚动

## 断点策略

- Tailwind `lg=1024` 分界侧栏常驻/抽屉；`sm=640` 分界工具条堆叠/横排。

## 交互约束

- 不依赖 hover 唯一交互；操作按钮均可点击。
- 触控热区 ≥ 44px（按钮/分页项）。
- 搜索 200ms 防抖；排序点击表头切换升/降序。
